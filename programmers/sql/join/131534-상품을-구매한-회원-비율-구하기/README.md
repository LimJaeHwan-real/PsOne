# 상품을 구매한 회원 비율 구하기

- 플랫폼: 프로그래머스
- 난이도: Level 5
- 분류: SQL / JOIN / GROUP BY / DISTINCT / 서브쿼리
- DBMS: MySQL
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/131534

## 문제 요약

2021년에 가입한 회원 중 상품을 구매한 회원 수와 구매 회원 비율을 년, 월별로 조회한다.

구매 회원 비율은 월별 구매 회원 수를 2021년에 가입한 전체 회원 수로 나누어 구하고, 소수점 둘째 자리에서 반올림한다.

## 풀이

1. `USER_INFO`와 `ONLINE_SALE`을 `USER_ID`를 기준으로 연결한다.
2. `WHERE YEAR(JOINED) = '2021'`로 2021년에 가입한 회원만 조회한다.
3. 판매 연도와 월을 기준으로 그룹화한다.
4. `COUNT(DISTINCT USER.USER_ID)`로 해당 월에 상품을 구매한 회원 수를 구한다.
5. 월별 구매 회원 수를 2021년 가입자 전체 수로 나누어 구매 회원 비율을 계산한다.
6. 연도와 월을 기준으로 오름차순 정렬한다.

## 배운 점

- `GROUP BY`로 연도와 월을 묶어도 한 회원이 같은 달에 여러 번 상품을 구매했다면 해당 회원의 판매 데이터가 여러 행 존재할 수 있다.
- 따라서 단순히 `COUNT`를 사용하면 같은 회원이 중복 집계될 수 있으므로 `COUNT(DISTINCT USER.USER_ID)`를 사용해야 월별 구매 회원 수를 정확하게 구할 수 있다.
- 이 풀이에는 프로그래머스에서 제출하여 통과한 코드를 그대로 기록했다.
