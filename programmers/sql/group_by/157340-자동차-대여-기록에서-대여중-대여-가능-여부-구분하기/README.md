# 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 분류: SQL / GROUP BY / MAX / CASE / BETWEEN / ORDER BY
- DBMS: MySQL
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/157340

## 문제 요약

자동차별로 2022년 10월 16일에 대여 중인지 확인해 `AVAILABILITY`에 '대여중' 또는 '대여 가능'을 표시한다.

대여 종료일이 2022년 10월 16일인 경우에도 '대여중'으로 표시하고, 자동차 ID를 기준으로 내림차순 정렬한다.

## 풀이

1. `GROUP BY CAR_ID`로 같은 자동차의 대여 기록을 묶는다.
2. `'2022-10-16' BETWEEN START_DATE AND END_DATE`로 기준일이 대여 기간에 포함되는지 확인한다.
3. MySQL에서는 조건식이 참이면 1, 거짓이면 0으로 계산되므로, `MAX`로 자동차별 조건식의 최댓값을 구한다.
4. 어느 한 기록이라도 조건을 만족하면 최댓값이 1이므로, `CASE`로 '대여중'을 표시한다. 모든 기록이 조건을 만족하지 않으면 '대여 가능'을 표시한다.
5. `ORDER BY CAR_ID DESC`로 자동차 ID를 내림차순 정렬한다.

## 배운 점

- MySQL에서는 조건식 자체가 참이면 1, 거짓이면 0으로 계산된다는 점을 이용하면 간단하게 쓸 수 있다.
- 조건식이 참일 때 1로 계산된다는 점을 이용해, 같은 자동차의 대여 기록 중 어느 한 행이라도 조건에 해당하면 `MAX`로 '대여중'임을 판단할 수 있다는 것을 알게 되었다.
- `BETWEEN`은 시작일과 종료일을 모두 포함하므로, 기준일이 대여 종료일과 같아도 '대여중'으로 판단한다.
