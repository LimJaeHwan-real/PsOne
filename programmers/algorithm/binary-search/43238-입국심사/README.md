# 입국심사

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 분류: 이분 탐색 / Parametric Search
- 언어: Python
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43238

## 문제 요약

모든 사람이 입국심사를 마치는 데 걸리는 최소 시간을 구한다.

## 핵심 아이디어

이 문제는 정답 시간을 바로 계산하는 대신, 특정 시간이 주어졌을 때 모든 사람을 처리할 수 있는지 판정하는 문제로 바꾼다.

```text
"28분이 정답인가?"를 바로 구하려 하지 말고

"28분이면 6명을 처리할 수 있는가?"
라는 Yes / No 문제로 바꾼다.
```

### 초급: `mid`분이면 몇 명을 처리할 수 있을까?

예제가 다음과 같다고 해보자.

```python
n = 6
times = [7, 10]
```

28분 동안 각 심사관이 처리할 수 있는 인원은 다음과 같다.

```text
7분 심사관:  28 // 7  = 4명
10분 심사관: 28 // 10 = 2명

총 6명 처리 가능
```

공장에 제품을 만드는 기계가 두 대 있다고 생각할 수도 있다.

```text
기계 A: 제품 하나를 만드는 데 7분
기계 B: 제품 하나를 만드는 데 10분

28분 동안

A: ■ ■ ■ ■    4개
B: ■ ■        2개

총 6개 생산 가능
```

마찬가지로 이 문제에서도 사람을 어느 심사대에 배치할지 직접 결정할 필요가 없다.

우리가 알고 싶은 것은 배치 방법이 아니라 **특정 시간까지 모든 심사관이 처리할 수 있는 최대 인원**이다.

### 중급: 왜 이분 탐색이 가능한가?

시간이 증가하면 처리 가능한 인원은 다음과 같이 변한다.

```text
시간     처리 가능 인원

20분          4명
21분          5명
22분          5명
...
27분          5명
28분          6명
29분          6명
30분          7명
```

`n = 6`이라면 판정 결과는 다음과 같다.

```text
1~27분    → 불가능
28분      → 가능 ← 찾으려는 최소 시간
29분 이상 → 가능
```

이를 가능 여부로 나타내면 다음과 같다.

```text
False False False ... False | True True True ...
                              ↑
                           최초의 True
```

시간을 더 줬는데 처리 가능한 인원이 감소하는 일은 없다. 이처럼 판정 결과가 한 방향으로만 변하는 성질을 **단조성**이라고 한다.

따라서 이분 탐색으로 **처음으로 가능한 시간이 되는 지점**을 찾을 수 있다.

### 고급: 배열이 아니라 정답의 범위를 탐색한다

일반적인 이분 탐색은 정렬된 배열에서 원하는 값을 찾는다.

하지만 이 문제는 배열이 아니라 **정답이 될 수 있는 시간의 범위**를 탐색한다.

```text
1분 ---------------------------------- 최대 시간
                     ↑
                    mid
```

`mid`분 동안 처리할 수 있는 인원은 다음과 같이 계산한다.

```python
people = sum(mid // time for time in times)
```

판정 기준은 다음과 같다.

```python
people >= n
```

- `True`이면 `mid`가 정답일 수도 있으므로 `right = mid`
- `False`이면 시간이 부족하므로 `left = mid + 1`

이처럼 정답 후보를 가정하고 가능 여부를 판정하면서 정답 범위를 줄이는 방식을 **정답 이분 탐색(Parametric Search)**이라고 한다.

## 알고리즘

1. 탐색 범위를 `1`부터 `min(times) * n`까지 설정한다.
2. 중간 시간 `mid`에서 처리 가능한 인원을 계산한다.
3. 처리 가능 인원이 `n`명 이상이면 `right = mid`로 줄인다.
4. 처리 가능 인원이 `n`명보다 적으면 `left = mid + 1`로 늘린다.
5. 탐색이 끝난 `left`를 반환한다.

## 시간 복잡도

심사관 수를 `k`, 탐색 범위의 최댓값을 `M`이라고 하면 시간 복잡도는 `O(k log M)`이다.
