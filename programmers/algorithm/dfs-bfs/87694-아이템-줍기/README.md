# 아이템 줍기

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 분류: 알고리즘 / BFS / 최단 거리 / 좌표 확대
- 언어: Java
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/87694?language=java

## 문제 요약

겹쳐진 직사각형으로 만든 지형의 가장 바깥쪽 테두리를 따라 캐릭터가 이동한다.
상하좌우로 움직여 아이템에 도달할 때 이동 거리의 최솟값을 구한다.

## 풀이

1. 직사각형, 캐릭터, 아이템의 좌표를 모두 2배로 늘린다.
2. 모든 직사각형의 테두리와 내부를 `map`에 `1`로 표시한다.
3. 모든 직사각형의 내부를 `0`으로 지워 이동 가능한 테두리만 남긴다.
4. 캐릭터의 위치를 큐에 넣고 `visited` 값을 `1`로 설정한다.
5. BFS로 상하좌우를 탐색한다. 좌표 범위 안에서 테두리이고 아직 방문하지 않은 위치만 이동한다.
6. 다음 위치에 현재 방문 값보다 `1` 큰 값을 기록한다.
7. 아이템 위치의 방문 값에서 시작점의 `1`을 빼고, `2`로 나누어 원래 이동 거리를 반환한다.

## 핵심 아이디어

### 좌표를 2배로 늘리는 이유

원래 격자에서는 서로 다른 테두리의 점들이 한 칸 차이로 붙어 보일 수 있다.
이때 BFS가 실제 테두리에 없는 구간을 가로질러 이동하면 거리를 잘못 계산한다.

좌표를 2배로 늘리면 두 점 사이에 중간 칸이 생긴다.
테두리가 이어진 구간만 중간 칸에 `1`이 남으므로 실제 경로를 따라 탐색할 수 있다.
이동 거리도 2배가 되므로 마지막에 `2`로 나눈다.

### 전체를 채운 뒤 내부를 지우는 이유

한 직사각형의 테두리가 다른 직사각형의 내부에 놓이면 이동 경로가 될 수 없다.
모든 직사각형을 먼저 채운 뒤 내부를 한꺼번에 지워야, 이미 지운 내부가 나중에 다시 채워지는 것을 막을 수 있다.

중앙에 빈 공간이 있으면 그 공간의 테두리도 배열에 남을 수 있다.
하지만 문제에서 캐릭터와 아이템은 바깥쪽 테두리에 있고, BFS는 시작점과 연결된 테두리만 탐색한다.

### 방문 값과 실제 거리

`visited`는 `0`을 미방문 표시로 사용하므로 시작점에는 `1`을 기록한다.
따라서 확대된 격자에서의 이동 거리는 `visited[iy][ix] - 1`이다.
최종 답은 `(visited[iy][ix] - 1) / 2`로 계산한다.

## 복잡도

직사각형 수를 `R`, 확대된 좌표의 최대값을 `M`이라고 하면:

- 시간 복잡도: `O(R × M² + M²)` — 직사각형 표시와 내부 제거, BFS 탐색
- 공간 복잡도: `O(M²)` — 지도, 방문 배열, 큐

문제에서 `R`은 최대 4, `M`은 최대 100이며 배열은 `102 × 102`를 사용한다.
