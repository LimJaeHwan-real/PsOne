# 단어 변환

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 분류: 알고리즘 / DFS / BFS / 백트래킹
- 언어: Java
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43163?language=java

## 문제 요약

`begin`에서 `target`까지 한 번에 알파벳 한 글자만 바꾸며 변환한다.

변환할 수 있는 단어는 `words`에 있는 단어뿐이며, 가장 적은 변환 횟수를 반환한다. `target`으로 변환할 수 없으면 `0`을 반환한다.

## DFS 풀이

1. `target`이 `words`에 없으면 변환할 수 없으므로 바로 `0`을 반환한다.
2. 현재 단어와 후보 단어의 각 글자를 비교해, 한 글자만 다를 때만 다음 단계로 이동한다.
3. 이미 사용한 단어는 `visited`로 다시 선택하지 않는다.
4. 후보 단어를 방문 처리한 뒤 DFS를 호출하고, 호출이 끝나면 방문 처리를 되돌린다. 이렇게 모든 변환 경로를 탐색한다.
5. `target`에 도달한 경로마다 변환 횟수의 최솟값을 `answer`에 기록한다.

## BFS 풀이

1. 현재 단어와 지금까지의 변환 횟수를 `Node`로 묶어 큐에 넣는다.
2. 큐에서 꺼낸 단어가 `target`이면, BFS 특성상 처음 도달한 횟수가 최단 변환 횟수다.
3. 아직 방문하지 않았고 현재 단어와 한 글자만 다른 `words`의 단어를 큐에 넣는다.
4. 큐가 비어도 `target`에 도달하지 못하면 `0`을 반환한다.

## 배운 점

- Java 문자열 내용은 `==`가 아니라 `equals()`로 비교한다.
- DFS에서 방문 처리를 되돌리면 다른 변환 경로도 빠짐없이 탐색할 수 있다.
- BFS는 큐에 먼저 들어온 낮은 변환 횟수의 경로부터 처리하므로, `target`에 처음 도달한 횟수가 최단 거리다.
- 탐색 후에도 `answer`가 초기값이면 변환 경로가 없으므로 `0`을 반환한다.
