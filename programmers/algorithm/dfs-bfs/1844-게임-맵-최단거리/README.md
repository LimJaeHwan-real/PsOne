## 문제 요약

벽과 길로 이루어진 게임 맵의 왼쪽 위에서 출발해 오른쪽 아래까지 이동한다.

상하좌우로 한 칸씩 움직일 때 지나가는 칸 수의 최솟값을 구하고, 목적지에 도달할 수 없으면 `-1`을 반환한다.

## 풀이

1. 시작 위치를 큐에 넣고 방문 거리를 `1`로 기록한다.
2. 큐에서 현재 위치를 꺼내 상하좌우의 다음 위치를 확인한다.
3. 맵 밖이거나 벽이거나 이미 방문한 위치는 건너뛴다.
4. 이동할 수 있는 위치를 큐에 넣고 현재 거리보다 `1` 큰 값을 기록한다.
5. 탐색이 끝난 뒤 목적지의 방문 거리가 `0`이면 `-1`, 아니면 기록된 최단 거리를 반환한다.
