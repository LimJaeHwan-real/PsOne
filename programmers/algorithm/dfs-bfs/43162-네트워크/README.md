# 네트워크

- 플랫폼: 프로그래머스
- 난이도: Level 3
- 분류: 알고리즘 / DFS / 그래프 탐색
- 언어: Java
- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43162?language=java

## 문제 요약

컴퓨터의 연결 정보가 담긴 2차원 배열 `computers`가 주어진다.

직접 또는 간접으로 연결된 컴퓨터들을 하나의 네트워크로 보고, 전체 네트워크의 개수를 구한다.

## 풀이

1. 그래프가 다 연결되어있지 않은 경우에는 네트워크의 갯수는 노드 수가 된다.
2. 그래프의 모든 노드에 출발점을 둬서 dfs를 호출하고 네트워크 수를 센다. (단 방문하지 않았다면 호출)
3. dfs 함수에서는 방문된 노드면 종료한다.
   방문되지 않았고 간선이 존재하면 다시 재귀호출한다.
